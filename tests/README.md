# 蜜蜂設定相容性驗證

在 MOD 目錄執行 `lua tests/bee_settings_migration.lua`。測試涵蓋四種 locale 的布林選單、工坊 1.0.1 舊字串的執行時解析、新版布林值原樣讀取、舊 dedicated override 及實際 config.lua／bees.lua hooks。

本 MOD 不再提供前端自動遷移或儲存功能。離線測試不代表遊戲前端與行為已通過實測；語法檢查使用本機 Lua 5.5，MOD 保持 Lua 5.1 寫法。

## 更新後的手動設定

從工坊 1.0.1 更新後，舊蜜蜂值可能顯示 N/A。請在主機的 MOD 設定中重新選擇以下三項並保存，再重開設定頁確認。不要只依據 N/A 判斷執行時值。

| 舊 `no_group_aggro_bee` | 蜜蜂／蜂巢／蜂箱 |
| --- | --- |
| `false` | `false` / `false` / `false` |
| `"bee"` | `true` / `true` / `true` |
| `"killerbee"` | `true` / `false` / `true` |

未被選單改寫的舊字串仍能在執行時讀取；若缺少蜂巢與蜂箱獨立值，沿用上表。若已儲存獨立值，以獨立值為準。此相容處理不修改設定檔。

## 遊戲內驗證

- 確認三項都只有兩個選項。手動儲存後關閉選單、重開遊戲與重載世界，確認不再顯示 N/A，且其他生物設定沒變。
- 主機與遠端玩家分別攻擊／捕捉普通蜜蜂及殺人蜂；檢查蜂群傳播、被打的蜂反擊與蜂巢放蜂種類／目標。蜂巢關閉時應放有目標的殺人蜂，開啟時放無目標的普通蜜蜂。
- 蜂箱及隱士蜂箱測採蜜與其他放蜂反應；蜂箱關閉時保留原版，開啟時採蜜不放蜂。必要時與停用 MOD 的原版世界對照。
- 專用伺服器地表／洞穴保留舊 `modoverrides.lua` 啟動、存檔重載，確認舊三種設定與缺少新 key 的行為不變，檔案內容不被遷移程式改寫。
- 若搭配其他改蜜蜂或設定介面的 MOD，再測一次設定儲存與載入。

使用者已回報先前自動遷移未生效；自動遷移程式已移除。上述手動設定與遊戲行為仍需實測。
