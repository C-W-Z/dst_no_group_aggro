# 蜜蜂設定遷移驗證

在 MOD 目錄執行 `lua tests/bee_settings_migration.lua`。測試涵蓋四種 locale 的布林選單、工坊 1.0.1 的單一蜜蜂選項（原版／選項1／選項2）、新版布林值原樣保留、重複遷移、舊 dedicated override、前端儲存重載與其他 MOD 不受影響。不支援未發布版本的 `"inherit"` 等中間格式。

離線測試使用模擬的設定儲存介面，不代表已驗證 DST 實際的前端時序或遊戲行為。語法檢查使用本機 Lua 5.5，MOD 程式碼維持 Lua 5.1 寫法。

## 遊戲內測試（尚未執行）

使用測試世界或備份設定，分別準備以下舊設定後更新並啟用 MOD。已啟用時，可離開並重新進入建立伺服器頁，讓 MOD 重新執行前端入口。

| 舊 `no_group_aggro_bee` | 更新後蜜蜂／蜂巢／蜂箱 |
| --- | --- |
| `false` | `false` / `false` / `false` |
| `"bee"` | `true` / `true` / `true` |
| `"killerbee"` | `true` / `false` / `true` |

- 在選單顯示前應選中遷移後的值；三項都只有兩個選項。關閉選單、重開遊戲後，確認設定仍在，且其他生物設定沒變。
- 修改成不同的三個布林值並儲存，重開設定頁與重載世界，確認不會再次繼承舊值。剛下載但尚未在前端啟用的 MOD 不會先執行遷移；先啟用，再檢查設定。
- 主機與遠端玩家分別攻擊／捕捉普通蜜蜂及殺人蜂；檢查蜂群傳播、被打的蜂反擊與蜂巢放蜂種類／目標。蜂巢關閉時應放有目標的殺人蜂，開啟時放無目標的普通蜜蜂。
- 蜂箱及隱士蜂箱測採蜜與其他放蜂反應；蜂箱關閉時保留原版，開啟時採蜜不放蜂。必要時與停用 MOD 的原版世界對照。
- 專用伺服器地表／洞穴保留舊 `modoverrides.lua` 啟動、存檔重載，確認舊三種設定與缺少新 key 的行為不變，檔案內容不被遷移程式改寫。
- 若搭配其他改蜜蜂或設定介面的 MOD，再測一次設定儲存與載入。

前端會透過 DST 的 `SaveConfigurationOptions` 更新本 MOD 的設定檔。需要回復時使用事前備份；這段程式不改寫世界內容或其他 MOD 的設定。
